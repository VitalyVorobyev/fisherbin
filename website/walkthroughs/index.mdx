# Walkthroughs

*Who this is for: a reader who wants one applied question followed end to end, with real
numbers, rather than a method described in the abstract.*

A walkthrough here is a single input route — score events, an analytic density, a classifier
ratio, a real dataset — taken from the raw problem to a fitted result, with the numbers that came
out and what they mean. It is not a tutorial on the whole library and not a restatement of the
reference; it exists to show one route worked all the way through.

This section is being filled in. Four walkthroughs are planned, one per input route. None of the
four pages below exists yet — this index lists what each will cover and, for the three routes
where the material already exists somewhere else, links to where it lives today so nothing is
unreachable while the walkthrough itself is still unwritten.
