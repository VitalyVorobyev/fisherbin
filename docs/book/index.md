# Information-preserving hard quantization

This book develops score-space quantization as a statistical subject independently of the
ScoreQuant package interface. It starts from likelihoods and measures, derives the information
algebra of hard labels, separates three optimization problems, and then treats trace, D,
profiled-\(D_s\), E, randomized rules, score estimation, and diagnostics.

Every substantive statement is tagged as one of:

- **Theorem** — a mathematical claim with stated assumptions and a proof or proof sketch;
- **Proposition** — a narrower derived claim;
- **Numerical evidence** — a reproducible computation, not a proof;
- **Open problem** — a question for which this project does not claim a result.

Small analytic or rational laboratories illustrate exact claims. The FlowCyt study is a capstone
application and never serves as proof.
